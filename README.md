# Heztio — Marketing site

Landing page for **heztio.com**. Static HTML + CSS, no build step. Part of the
**Heztio suite**.

## Edit & preview

```bash
open index.html                  # or:
python3 -m http.server 8080      # then http://localhost:8080
```

## Files

| Path | What |
| --- | --- |
| `index.html` | The whole site. |
| `colors_and_type.css` | Vendored Heztio design tokens (`--hz-*`) and `@font-face` rules. |
| `fonts/` | Causten (+ Montserrat / JetBrains Mono via Google Fonts). |
| `assets/` | Logos and lockups from the brand kit (`VisualIdentity/dist`). |
| favicons | `favicon.ico`, `favicon-*.png`, `apple-touch-icon.png`, `android-chrome-*.png`. |

## Rules

Follow `design.md` (hard rule) and `CLAUDE.md`. Copy is Spanish (Colombia, "tú").
